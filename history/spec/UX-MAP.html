source view — /install as plain text (N11)

#!/bin/sh
# shroom installer
#
# You're reading exactly what will run — this address serves
# one file, and this is it. Four things, in order:
#
# 1. Download the shroom app for your Mac.
# 2. Check it against its published fingerprint — if anything
# is off, nothing gets installed.
# 3. Place it in ~/Applications — no admin password, nothing
# outside your home folder.
# 4. Open it.
#
# Run it again anytime — that's also the update: same four
# steps, newer shroom. If shroom is in the middle of a
# recording, the script stops and changes nothing.
#
# Trouble, questions: github.com/bagrat/shroom/issues/new
# No GitHub? issues@shroom.am works too.
