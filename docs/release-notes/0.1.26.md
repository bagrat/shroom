- Each video you edit opens in a window of its own, so you can work on several at once. Edit on a video that's already open brings its window forward.
- Closing the editor with changes you haven't saved now asks first: Save, Keep editing or Discard.
- The shroom command can edit a video too: `shroom edit` trims it, cuts out a stretch or puts a cut back, and the link plays the edit from its next load.
- `shroom --version` now says which shroom you have.
- A pause or stop that takes a busy Mac a while no longer loses your recording.
